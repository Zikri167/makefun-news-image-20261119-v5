# The World in One Day — 19 November 2026

A single-page broadsheet that sums up the world news of Thursday, 19 November 2026 in one 1024×1024 image: the Trump–Xi–Putin summit in Shenzhen leads, flanked by the third strike on the Crimean Bridge and the UN court's genocide ruling on Myanmar, with a markets strip, an Anthropic-versus-Nvidia IPO infographic, the COP31 fossil-fuel row and Voyager 1 reaching one light-day in the second tier, fourteen further stories in a dense four-column grid under section kickers, a "Day in Numbers" box, and thirteen one-line briefs — 34 stories on one page. The Python program (`main.py`, standard library only) validates the bundled `entry.png` and copies it byte-for-byte to the output directory.
